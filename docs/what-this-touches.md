# What this touches on your machine

Generated from `tools/*/manifest.conf` by `lib/manifest.sh`. Do not edit this file by
hand. CI regenerates it and fails if the result differs from what is checked in.

If a path is not on this page, no tool in this repo writes it.

Two paths are shared by all three tools and are removed by hand:

```sh
rm -rf ~/.local/state/ccw ~/.config/ccw
```

## `open-binary`

Clickable binary file links in the Claude Code VS Code chat panel.

| path | what it is | undo |
|---|---|---|
| `~/.vscode{,-insiders}/extensions/anthropic.claude-code-*/extension.js` | Patched in place, once per installed version. About 522 bytes go in, 662 with the click log on. | cp extension.js.ccw-open-binary.bak extension.js |
| `~/.vscode{,-insiders}/extensions/anthropic.claude-code-*/extension.js.ccw-open-binary.bak` | The pristine bundle, copied before the first write for that version. Fixed name because rollback and the version migration both read it back. | rm it after restoring |
| `~/Library/LaunchAgents/io.github.dthinkr.ccw.open-binary.plist` | launchd agent. WatchPaths on ~/.vscode/extensions and ~/.vscode-insiders/extensions, so it re-applies the patch after every extension upgrade. | launchctl bootout gui/$(id -u)/io.github.dthinkr.ccw.open-binary && rm -f the plist |
| `~/.local/state/ccw/open-binary` | patch.log (one line per run per version), runtime.log (one line per click, off unless you installed with --click-log), and the agent's stderr. | rm -rf it |

## `auto-compact`

Compact an idle Claude Code session while its prompt cache is still warm.

| path | what it is | undo |
|---|---|---|
| `~/Library/Application Support/Code/User/settings.json` | One key added: claudeCode.claudeProcessWrapper, pointing at shim/cc-stdin-shim in this checkout. Backed up first. Insiders has its own copy of this file and gets the same key. | remove that one key, or run ./cc-kit uninstall auto-compact |
| `~/Library/LaunchAgents/io.github.dthinkr.ccw.auto-compact.plist` | launchd agent. Runs compactd.py every 120 seconds. | launchctl bootout gui/$(id -u)/io.github.dthinkr.ccw.auto-compact && rm -f the plist |
| `~/.local/state/ccw/auto-compact` | state.json (per-session armed flags), compactd.log, and the agent's stdout and stderr. | rm -rf it |
| `/tmp/cc-inject` | One unix socket per live session that has picked up the shim, mode 600, removed when the session exits. | nothing to do, /tmp is cleared on reboot |

## `rc-proxy`

Send inference to a local gateway without losing any first-party Claude Code feature.

| path | what it is | undo |
|---|---|---|
| `<checkout>/tools/rc-proxy/claude-rc-proxy` | The binary, built here by go build. Gitignored. Never a Release download: an unsigned Mach-O trips Gatekeeper and produces one identical issue per user. | rm it |
| `~/Library/LaunchAgents/io.github.dthinkr.ccw.rc-proxy.plist` | launchd agent, KeepAlive. Reads your token from the config file at start, so the token never goes into the plist, which is world readable. | launchctl bootout gui/$(id -u)/io.github.dthinkr.ccw.rc-proxy && rm -f the plist |
| `~/.local/state/ccw/rc-proxy` | route.log (startup, model injections, errors; rotated to route.log.1 past 8 MiB) and pool-models.json (model ids seen in the last 7 days). | rm -rf it |
| `~/.config/ccw/rc-proxy.token` | Your gateway token, mode 600. You write this file, the installer only reads it. | rm it |
| `~/.claude/settings.json` | Four env keys: https_proxy, http_proxy, no_proxy, NODE_EXTRA_CA_CERTS. The installer prints them for you to paste and never edits this file itself. | delete those four keys from the env object by hand |

## Nothing else

No tool here copies itself to `~/.local/bin`, `~/.local/share` or `~/.claude/scripts`.
Every launchd plist points at a file inside this checkout by absolute path. That is why
`git pull` is the whole update procedure, and also why moving the checkout breaks the
agents.
